Amazon Product Decision Gateway

Validating a pilot decision request

简体中文

Input

Synthetic teaching case. A US Amazon organizer request asks whether to fund a 500-unit pilot with an 18% target contribution margin. The fixture begins with an empty evidence array.

Process

Validate the JSON version, product scope, marketplace and currency. Remove credentials and personal data, retaining evidence identifiers. A configured private service is required for request-bound responses.

Result

In repository tests, the valid request passes schema validation while the invalid fixture returns multiple errors. The response example demonstrates verdict enums and the stage matrix shape.

Decision

Use an authorized decision service with real evidence for a pilot decision. The sparse input and sample verdict illustrate the transport contract.
